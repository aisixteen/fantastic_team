# ui/chat_send_and_answer (free)

Sending and answering from the page (#351). Function only.

A message typed in Lead's composer reaches Lead alone, the scripted reply is drawn, and Lead's history holds both. k-rollout's question is answered with an option, m-ads's in the person's own words: `user` drops each, the asker's next model request holds the answer, and "Waiting for you" shrinks, then goes.
